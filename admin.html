Customer management

Customer profiles, account status, registration details and support history.

Backend integration requiredCustomer listing, search, account suspension and customer-detail APIs are not yet connected to this page.

Orders & trading

Buy and sell orders, payment verification, approvals, rejections and payout records.

Backend integration requiredThe order module has its own API foundation, but this page does not yet load or manage orders. Connect the exact order response fields and permission checks before enabling admin actions.
Automatic execution must remain disabled until a real execution provider is configured and tested. Manual payout confirmation is an admin attestation, not proof of an external bank or blockchain transfer.

Wallets & balances

Customer available balances, locked funds, platform inventory and ledger history.

Backend integration requiredWallet inspection, ledger search, reconciliation and controlled adjustment screens are not yet connected. No balance adjustment should be exposed until the backend enforces permissions, transaction references and audit records.

Payment settings

Configure bank transfer instructions and supported checkout providers.

Backend integration requiredBank details, payment methods, provider credentials and webhook verification need persistent settings and secure backend endpoints. A checkout link alone cannot confirm a payment.

Asset management

Control which crypto assets and networks are available to customers.

Backend integration requiredCustom asset creation, network configuration, visibility and maintenance controls need an asset-management API. Market listings must not automatically become tradable assets.

Pricing & fees

Manage trading prices, spreads, fixed fees and fiat conversion rates.

Admin pricing interface not connectedThe order module contains pricing endpoints, but this page does not yet load or save their settings. Price changes should be validated and audited by the backend.
Customer-submitted prices must never be trusted. Order amounts should be calculated and snapshotted by the server when an order is created.

Customer support & live chat

Support inbox, customer conversations, assignment and resolution.

Backend integration requiredPersistent chat messages, unread counts, staff assignment, replies and conversation status are not yet connected.

Notifications

Send platform announcements and manage customer notification records.

Backend integration requiredThe notification sending and customer notification-management APIs must be connected before this section can send or modify messages.

KYC verification

Review customer identity submissions and verification status.

Backend integration requiredDocument storage, secure access, review decisions and audit history are not yet connected. Sensitive identity documents must not be exposed through public URLs.

Website settings

Manage public contact details, support channels, service notices and platform availability.

Backend integration requiredPersistent global settings and admin-controlled support email, WhatsApp and maintenance mode are not yet connected.

Staff & security

Admin roles, permissions, login protection and administrative activity records.

Backend integration requiredCurrent role foundations are not a complete staff-management system. Database-backed staff invitations, role changes, 2FA and audit-log screens still need implementation.

Reports & financial records

Transaction summaries, trading volume, fees, exports and reconciliation reports.

Backend integration requiredFinancial reports must be generated from ledger and verified transaction records, not from customer-submitted order values.

System health

Application availability, database connection and service monitoring.

Limited health endpoint availableThe server has a basic health endpoint. Detailed database, market-provider, queue and integration monitoring still needs to be implemented.
